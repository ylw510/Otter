# 隐私说明

[English](privacy.en.md)

## 本地优先

推荐默认使用本地后端（`http://localhost:8000`），让词汇数据、上下文和 LLM 请求尽量留在你可控环境中。

## 数据流

1. 扩展 -> 后端：改写/解释/保存/复习请求
2. 后端 -> LLM：仅在后端配置供应商密钥时发生

## 本地与托管

- 本地模式：数据在你的设备
- 托管模式：数据在运营方基础设施
- OSS 默认下，可选 `Extension-Key` 仅用于本地门禁部署

## OSS 默认行为

- 不内置分析 SDK
- 不包含广告追踪器
- 扩展源码不携带 LLM 供应商密钥
