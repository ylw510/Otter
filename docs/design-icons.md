# Extension icons (Otter mascot)

Toolbar / extension list icons live under `extension/icons/` as PNG (`icon16.png`, `icon48.png`, `icon128.png`), generated from the vector source `otter-mascot.svg`.

- **Regenerate** after editing the SVG: from `extension/`, run `npm run icons` (requires devDependency `sharp`).
- **Attribution:** Original vector artwork for this repository; see repository `LICENSE`.

Related: [Issue #7](https://github.com/ylw510/Otter/issues/7).
